# Teitunnel 0.4.0

Sign in with GitHub or Google, bypass Cloudflare's cache for a dev server, and faster
imports.

## Highlights

- **GitHub and Google sign-in.** A route's login can let in the members of a GitHub
  organization (`github:teispace`) or one of its teams (`github:teispace/Developers`), and
  can be limited to the account's GitHub or Google login method, so visitors go straight
  to it. Choose **Log in with** in the route sheet, or use `--allow github:…` and
  `--sign-in github|google` in the terminal. The login method is set up once in the
  Cloudflare dashboard, where its client secret stays.
- **Bypass the cache.** Changes to a dev server shared on your domain can show an old,
  cached copy. Turn on **Bypass Cloudflare's cache** in **Edit Protection…**, or run
  `teitunnel protect <hostname> --bypass-cache`, and Cloudflare stops caching that hostname
  only. It needs the new, optional **Zone ▸ Cache Rules ▸ Edit** permission; tokens
  without it keep every other protection working.
- **Faster imports.** Importing several routes creates their DNS records in one call per
  domain, applied all or nothing, instead of one call per route.

What's new, with a link to each guide: https://teitunnel.teispace.com/docs/getting-started/whats-new

## Fixes

- The Linux AppImage now includes the tray library, so the tray icon shows even where the
  system doesn't have it.
- Messages about a missing permission now also say how to add it when you signed in with
  Cloudflare, not only with an API token.
- Links from errors to the Cloudflare dashboard open the right Zero Trust pages again.

## Install

The app updates itself (**Restart to Update**). Or download Teitunnel from
**https://teitunnel.teispace.com/download**, or:

- macOS: `brew install --cask teispace/tap/teitunnel`
- Servers: the `teitunnel` archives below, the apt/dnf repository, or the Docker image
  `teispace/teitunnel` (also `ghcr.io/teispace/teitunnel`).

Every download is listed in `SHA256SUMS.txt` and carries GitHub build provenance
(`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- Windows builds are not code-signed yet, so Windows may show "Windows protected your PC":
  choose **More info ▸ Run anyway**.
- The browser extension isn't in the Chrome Web Store or Firefox Add-ons yet.
- Accounts connected with **Sign in with Cloudflare** get the Cache Rules permission after
  signing in again; with an API token, add it to the token.
