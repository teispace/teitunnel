# Teitunnel 0.5.0

A home for AI apps and integrations, private hostnames for WARP users, and safer approvals
for AI agents.

## Highlights

- **AI & Integrations.** AI apps, agents, shared MCP servers, the browser extension and
  other programs have their own section in the sidebar. AI apps are found by the installed
  app, not a leftover settings folder, and each says where it stands: connected (and when an
  agent last used it), needs updating, left over or not connected. **Test Connection**
  starts the server the way the app would and lists its tools. New: GitHub Copilot CLI,
  opencode, Kiro, LM Studio and Junie. Each browser is set up on its own and shows when the
  extension last connected.
- **Private hostnames.** Share a name such as `wiki.internal` with WARP users, next to
  private IP ranges: `teitunnel network add wiki.internal`, or the **Share a Private
  Network** sheet. This machine resolves the name, so no DNS record is needed. The Doctor
  reports a shared name this machine can't resolve.
- **Approvals that need a person.** In `ask` mode an agent saying you agreed is no longer
  enough: the change waits for your answer in Teitunnel or in your AI tool
  (`approveInApp`, on by default). Teitunnel supports MCP protocol 2026-07-28, and results
  that hold outside content (traffic, comments, logs) are marked as untrusted data.
- **Harder OAuth for shared MCP servers.** Refresh tokens rotate safely, a connection you
  end in the app ends at once everywhere, connections expire after 90 days, and sign-ins are
  rate limited.

What's new, with a link to each guide: https://teitunnel.teispace.com/docs/getting-started/whats-new

## Fixes

- `teitunnel share --on` finds the app's connector where the app runs it, instead of
  starting a second one when the remembered port was out of date.
- `teitunnel mcp status` says when an entry's `teitunnel` is gone or its app was removed.

## Install

The app updates itself (**Restart to Update**). Or download Teitunnel from
**https://teitunnel.teispace.com/download**, or:

- macOS: `brew install --cask teispace/tap/teitunnel`
- Servers: the `teitunnel` archives below, the apt/dnf repository, or the Docker image
  `teispace/teitunnel` (also `ghcr.io/teispace/teitunnel`).

Every download is listed in `SHA256SUMS.txt` and carries GitHub build provenance
(`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- Windows builds are not code-signed yet, so Windows may show "Windows protected your PC":
  choose **More info ▸ Run anyway**.
- The browser extension isn't in the Chrome Web Store or Firefox Add-ons yet.
- Private hostname routes are new: tell us on
  [#48](https://github.com/teispace/teitunnel/issues/48) how they work for you.
