# Teitunnel 0.1.0 (public beta)

A native control center for Cloudflare Tunnel on macOS, Windows and Linux: share local
apps on your own domains, keep them running, and see what's happening, without editing
config files.

## Highlights

- **Quick Share.** A public `trycloudflare.com` URL for any local port in seconds, no
  account needed, or an address on your own domain that goes away when you stop sharing.
- **Routes on your domains.** Pick a service and a hostname; Teitunnel shows every change
  to DNS and your tunnel before it makes it, and can undo it.
- **Keep running.** Routes can run as a system service, so they stay up after you quit
  the app or restart the computer.
- **See what's happening.** Live traffic, logs per route, an activity history and a
  Doctor that finds broken DNS, stopped connectors and permission gaps, with fixes in
  place.
- **Logins, private networks, load balancing.** Put a Cloudflare Access login in front
  of a route, share a private network with WARP clients, or serve one hostname from
  several machines.
- **Servers too.** `teitunnel-cli` does the same from a terminal, a VPS or a container,
  and `teitunnel-cli serve` adds a small web dashboard.

## Install

Download Teitunnel for your system from **https://teitunnel.teispace.com/download**.

- **macOS 14 or later** (Apple silicon and Intel): open the `.dmg` and drag Teitunnel to
  Applications. The app is signed and notarized by Teispace.
- **Windows 10 and 11** (x64 and arm64): run the setup. This beta isn't code-signed yet,
  so Windows may show "Windows protected your PC": choose **More info ▸ Run anyway**.
- **Linux** (x64 and arm64): the `.deb` for Ubuntu and Debian, the `.rpm` for Fedora and
  openSUSE, or the AppImage for anything else.

Teitunnel updates itself from now on. Every download is listed in `SHA256SUMS.txt` and
carries GitHub build provenance (`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- This is a beta: expect rough edges, and please report them at
  https://github.com/teispace/teitunnel/issues.
- Windows builds are unsigned until code signing through SignPath Foundation is in place.
- Windows and Linux have been tested in CI, not yet on many real machines.
