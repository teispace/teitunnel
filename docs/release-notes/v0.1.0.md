# Teitunnel 0.1.0: developer preview

Share anything running on your Mac at a public URL in one click. No Cloudflare account needed.

## What's in this release

- **Quick Share.** Pick a detected dev server (Vite, Next.js, Django, …) or type a port, and get a `trycloudflare.com` URL with a QR code, live request count, log and optional auto-stop. Run several at once.
- **cloudflared, handled.** Uses your existing cloudflared (e.g. Homebrew) or installs Cloudflare's official release into Teitunnel's own folder. Downloads are verified against GitHub's digest, Cloudflare's published checksum and Cloudflare's code signature.
- **Native macOS app.** Sidebar vibrancy, system accent colour, light and dark, full menu bar and keyboard shortcuts, a menu bar extra listing your shares, and notifications when a share goes live in the background.
- **No leftovers.** Quitting stops every share; if Teitunnel is force-quit, leftover connectors are stopped on next launch.

## Install

1. Download `Teitunnel_0.1.0_universal.dmg` and drag Teitunnel to Applications.
2. This preview isn't notarized yet. The first time, right-click Teitunnel in Applications and choose **Open**, then confirm. (Or: System Settings → Privacy & Security → **Open Anyway**.)

Verify the download: `shasum -a 256 Teitunnel_0.1.0_universal.dmg` should match `SHA256SUMS.txt`.

## Known limitations

- macOS only for now; Windows and Linux follow after 1.0.
- Custom domains (routes) arrive in 0.2 and 0.3.
