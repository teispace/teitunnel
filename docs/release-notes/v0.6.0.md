# Teitunnel 0.6.0

Dashboards that use the whole window, Cloudflare sign-ins that stay signed in, and loading
you can see.

## Highlights

- **A dashboard Overview.** A status banner, then cards for traffic, errors, edge round trip,
  uptime, routes and Quick Shares; a live traffic chart, the response mix (2xx, 3xx, 4xx,
  5xx), routes, Quick Shares, recent requests and activity. On a large display the cards
  spread across the window, up to six in a row, instead of sitting in a narrow column.
- **Analytics at a glance.** The account's totals for the period (requests, data served,
  server errors, slowest P95, lowest uptime, busiest route), requests over time and the top
  routes, above the per-route table.
- **Sign-ins that stay signed in.** Cloudflare's refresh tokens change on every use. Accounts
  from one sign-in used to refresh separately, and Cloudflare ended the sign-in, so you had to
  sign in again and again. They now share one token. When a sign-in does end, the account
  shows **Signed out** with **Sign In Again**, in Settings and on any page that needed it,
  and Teitunnel stops retrying it.
- **You can see it working.** Pages show their shape with a shimmer while they load, and a
  thin bar under the toolbar moves while data loads or a change runs, so a slow answer no
  longer looks like a hang.

What's new, with a link to each guide: https://teitunnel.teispace.com/docs/getting-started/whats-new

## Fixes

- The Doctor listed warnings in two groups when this computer's local domains had findings.
- Installing cloudflared retries requests GitHub couldn't answer, names GitHub's rate limit,
  stops a download that stalls for 30 seconds instead of waiting forever, and uses
  `GITHUB_TOKEN` for the release lookup when set (CI).
- The database gives the space of pruned inspector history back to the disk (it is switched
  to incremental auto-vacuum once, at the first start).
- Background Doctor runs reuse a recent permission check instead of asking Cloudflare every
  time.
- Quick Share puts cards two across in a wide window; detail panes keep a readable width.
- Dependency updates with security fixes (rusqlite, Next.js, Vite, zod).

## Install

The app updates itself (**Restart to Update**). Or download Teitunnel from
**https://teitunnel.teispace.com/download**, or:

- macOS: `brew install --cask teispace/tap/teitunnel`
- Servers: the `teitunnel` archives below, the apt/dnf repository, or the Docker image
  `teispace/teitunnel` (also `ghcr.io/teispace/teitunnel`).

Every download is listed in `SHA256SUMS.txt` and carries GitHub build provenance
(`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- Windows builds are not code-signed yet, so Windows may show "Windows protected your PC":
  choose **More info ▸ Run anyway**.
- The browser extension isn't in the Chrome Web Store or Firefox Add-ons yet.
- Private hostname routes are new: tell us on
  [#48](https://github.com/teispace/teitunnel/issues/48) how they work for you.
