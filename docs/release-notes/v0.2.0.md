# Teitunnel 0.2.0

The biggest release since the first beta. Teitunnel now inspects traffic, publishes static
copies of sites, protects hostnames at Cloudflare's edge, serves local HTTPS domains and
works with AI agents, and you can sign in with Cloudflare instead of creating a token.

> **Using 0.1.x? Update before 5 October 2026.** From that day Cloudflare's tunnel list no
> longer includes each tunnel's connections. 0.2.0 reads them from Cloudflare's new
> endpoint; 0.1.x would show every tunnel as if no machine ran it. The app updates itself
> (**Restart to Update**).

## Highlights

- **Sign in with Cloudflare.** One consent screen instead of an API token. A missing
  permission is fixed in place, and an account without Zero Trust gets a setup card
  instead of an error. The app, the `teitunnel` command and AI agents share one sign-in.
- **The inspector.** Every request to a share or route: headers, bodies and timing. Replay,
  edit and export them (cURL, HAR…), with credentials masked. Throttle the network or
  inject failures on purpose, and draft an OpenAPI description from real traffic.
- **Snapshots.** A static copy of a folder, a build or a running site on your own
  Cloudflare account, online while your computer sleeps, with versions, passwords, logins
  and reviewer **comments**.
- **Offline page and webhook inbox.** Your own page instead of error 1033 while your
  computer is off, and webhooks kept and delivered in order when it's back.
- **Edge protection.** Challenge or block bots and AI crawlers, rate limit visitors and
  set headers for one hostname; **service tokens** let CI and scripts through a login.
- **Local HTTPS domains.** `https://shop.test`, `app.localhost` or `name.local` with a
  certificate your browsers trust, no Cloudflare account needed.
- **Sharing, smoother.** Dev servers that refuse a public host are fixed in one click;
  pause, resume and schedule shares on your domain; share a folder; one-click sharing from
  the menu bar; an exposure check before anything goes public.
- **AI agents.** An MCP server for Claude Code, Cursor, VS Code, Codex and more, connected
  from **Settings ▸ AI Tools**. You approve every change in the app, and secrets never
  reach the agent.
- **Automation and teams.** `teitunnel.yml` project files, pull request previews for GitHub
  and GitLab, hostname reservations, `teitunnel://` links and extensions for VS Code,
  Raycast and JetBrains IDEs.
- **Analytics, uptime and alerts** per hostname, and an encrypted backup to move to a new
  computer.

Everything, with a link to each guide: https://teitunnel.teispace.com/docs/getting-started/whats-new

## Changes to know about

- **The command is `teitunnel`**, not `teitunnel-cli`, in the archives, Homebrew, the Linux
  packages and the Docker image. It now comes with the app. Update scripts that call the
  old name.
- CI preview hostnames default to one level (`pr-42-preview.<your domain>`), which
  Cloudflare's free certificate covers.
- Teitunnel uses Cloudflare's current API throughout (tunnel connections, batch DNS
  changes, Access with reusable policies).

## Install

Download Teitunnel for your system from **https://teitunnel.teispace.com/download**, or:

- macOS: `brew install --cask teispace/tap/teitunnel`
- Servers: the `teitunnel` archives below, the apt/dnf repository, or the Docker image
  `teispace/teitunnel` (also `ghcr.io/teispace/teitunnel`).

Every download is listed in `SHA256SUMS.txt` and carries GitHub build provenance
(`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- Windows builds are not code-signed yet, so Windows may show "Windows protected your PC":
  choose **More info ▸ Run anyway**.
- Features that run on Cloudflare (Snapshots with passwords or comments, the offline page,
  the webhook inbox) count against your account's free Workers requests; see
  https://teitunnel.teispace.com/docs/reference/limits.
- Local HTTPS domains, the Windows control connection and Linux desktop integration have
  been tested in CI and on few real machines so far. Please report problems at
  https://github.com/teispace/teitunnel/issues.
