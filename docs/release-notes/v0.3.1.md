# Teitunnel 0.3.1

A fix for the Settings window on Windows.

## Fixes

- **Settings always opens.** If the Settings window failed to open (for example when
  Windows was asked to close the app at the same moment), it used to stay unavailable until
  Teitunnel restarted. The next click now opens a working Settings window.
- **One Settings window on a double-click.** Clicking Settings twice quickly could open a
  second, hidden window.

Thanks to [@sabin-poudel-46](https://github.com/sabin-poudel-46), who found and reported both
while testing on Windows ([#44](https://github.com/teispace/teitunnel/pull/44)).

## Install

The app updates itself (**Restart to Update**). Or download Teitunnel from
**https://teitunnel.teispace.com/download**, or:

- macOS: `brew install --cask teispace/tap/teitunnel`
- Servers: the `teitunnel` archives below, the apt/dnf repository, or the Docker image
  `teispace/teitunnel` (also `ghcr.io/teispace/teitunnel`).

Every download is listed in `SHA256SUMS.txt` and carries GitHub build provenance
(`gh attestation verify <file> --repo teispace/teitunnel`).

## Known limitations

- Windows builds are not code-signed yet, so Windows may show "Windows protected your PC":
  choose **More info ▸ Run anyway**.
