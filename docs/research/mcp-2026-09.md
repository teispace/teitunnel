# MCP: protocol, Rust SDK and AI clients (2026-09-24)

Facts behind M12-03 (`crates/mcp`, `teitunnel mcp`). Checked 2026-09-24.

## Protocol

- The **current** MCP revision is **2026-07-28**. It drops the `initialize` handshake for per-request metadata (`_meta` carries `io.modelcontextprotocol/protocolVersion`, client info and capabilities; Streamable HTTP also sends `MCP-Protocol-Version`), adds `server/discover`, multi round-trip requests (`InputRequiredResult`, SEP-2322), `subscriptions/listen`, and deprecates logging, sampling and roots (SEP-2577). Servers may support several versions; clients on the handshake-based revisions (2025-11-25 and earlier) keep working through backward compatibility. ([versioning](https://modelcontextprotocol.io/specification/versioning), [2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/))
- Most clients in use still speak **2025-11-25** (initialize, `resources/subscribe`, logging). Teitunnel serves both.
- Streamable HTTP security guidance: validate `Origin` (DNS rebinding), bind to localhost for local servers, authenticate. ([transports](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http))

## Rust SDK

- **`rmcp` 3.4.1** (crates.io, Apache-2.0), the official SDK (github.com/modelcontextprotocol/rust-sdk). Knows protocol versions 2025-03-26, 2025-06-18, 2025-11-25 and 2026-07-28 (`ProtocolVersion::KNOWN_VERSIONS`), negotiates per request, and gates MRTR to 2026-07-28 peers.
- Features used: `server`, `schemars` (JSON Schema 2020-12 for tool input/output schemas), `elicitation`, `transport-io` (stdio), `transport-streamable-http-server` (tower service; `allowed_hosts` defaults to loopback, `allowed_origins` + `enforce_origin_validation`, `LocalSessionManager` for `Mcp-Session-Id` sessions, `max_request_body_bytes`). Tests add `client`.
- Server-to-client requests (elicitation) must be sent while handling a client request from 2026-07-28 (SEP-2260); `Peer::create_elicitation_with_timeout` inside `call_tool` works for both eras.
- `schema_for_input`/`schema_for_output` (in `rmcp::handler::server::common`) generate draft 2020-12 schemas and check the input root is an object.
